# LGSPusula v0.2 - Test sürümü

Tek dosyalık HTML/CSS/JS demo. Build veya bağımlılık gerektirmez.

## Yerel test
`index.html` dosyasını tarayıcıda açın. Çalışmalar, dersler, kaynaklar, mentorluk ve raporları kontrol edin.

## Vercel
Kaynak: `yigitmst/lgspusula`, dal: `main`. Git kaynaklı test deployment oluşturuldu. Otomatik sonraki commit yayınları için Vercel Project → Settings → Git bağlantısının ayrıca kontrol edilmesi gerekir.

## Veri ve erişim
Tarayıcı localStorage'ı kullanılmaktadır. Rol seçenekleri demo amaçlıdır, erişim kontrolü **değildir**. Gerçek kişisel veri girilmemelidir.
